# MVP futuro

O MVP futuro deverá suportar o fluxo abaixo:

cliente solicita serviço
→ sistema entende a necessidade
→ identifica localização
→ encontra profissionais
→ apresenta opções
→ cliente escolhe profissional
→ contato é registrado
→ posteriormente é possível avaliar

Esse fluxo é apenas uma diretriz de produto neste momento; suas regras e integrações ainda não foram implementadas.

A base de dados já representa as entidades necessárias para esse fluxo, mas ainda não há busca, ranking, comunicação, autenticação ou interface de negócio.
